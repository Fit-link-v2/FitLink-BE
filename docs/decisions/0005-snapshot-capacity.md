# 슬롯의 정원은 생성 시점에 복사한다

## 맥락

`recurrence.capacity`(반복 규칙의 정원)를 강사가 나중에 바꿀 수 있다. 이미 만들어진 슬롯에 반영할지 정해야 했다(BE-0001 Q3).

## 결정

`class_slot.capacity`는 슬롯을 만들 때 `recurrence.capacity`를 복사한다. 규칙의 정원을 바꿔도 이미 만든 슬롯은 바뀌지 않는다.

## 검토한 대안

| 대안 | 버린 이유 |
|---|---|
| 슬롯이 규칙의 정원을 참조 | 이미 예약이 찬 슬롯의 정원이 줄어 `taken > capacity`가 된다. "그때 정원이 몇이었나"도 복원할 수 없다 |

## 대가

- 강사가 규칙 정원을 바꾸면 이미 만들어진 슬롯(오픈 범위 안, 기본 14일)은 예전 정원 그대로다. 강사가 기대하는 동작과 다를 수 있다

# 아키텍처 개요

> 1차 이전본. 계층 · 모듈 경계 · 기술 스택은 2차 이후 채운다.

## 문서의 위치

| 구분 | 상세 |
|---|---|
| 목적 | PRD 1~5의 User Story · 인수 조건에서 물리 테이블을 도출한다. 백엔드 구현의 출발점 |
| 입력 | PRD 0(상위 개념), PRD 1~5 본문과 각 하위 페이지의 US · AC |
| 제품 형태 | **개인 강사 단위 SaaS.** 강사가 각자 가입해 각자의 회원 · 시간표 · 설정만 본다. 한 사업장에서 여러 강사가 회원을 공유하는 것은 범위 밖 |
| 출력 | ERD 1장, 테이블 11개 DDL, AC 대 제약 매핑표, 쓰기 경로 3종, 설계 대가, 열린 질문 |
| DB | PostgreSQL 가정. `timestamptz`, 부분 인덱스(partial index), 조건부 UPDATE를 전제로 한다 |
| 상태 | 리뷰 요청 중. 열린 질문이 닫히기 전까지 확정 아님 |

PRD 1의 `6. 데이터` 섹션에 있던 관계도를 대체한다. 그쪽은 강사 1명 전제였고, PRD 3 AC 5.2.2가 요구하는 이력 테이블이 빠져 있었다.

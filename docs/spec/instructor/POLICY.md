# 강사 도메인 정책

> 코드가 **지금 실제로 지키는** 규칙을 적는다. 기능이 머지될 때 doc-sync에서 채운다. 설계상 규칙은 진행 중인 기능의 개발 PRD에 있다.

## 규칙

### 가입 · 로그인 (0001 Phase 1)

- 강사는 카카오 계정으로만 가입 · 로그인한다. 처음 보는 카카오 회원 번호로 로그인하면 강사 1명과 설정(오픈 범위 14일)이 함께 생긴다
- 카카오가 닉네임 · 이메일을 주지 않아도(강사가 동의하지 않아도) 가입한다. 이름 · 이메일은 비어 있다
- 카카오 계정 하나에 강사는 1명이다. 같은 계정의 로그인이 동시에 와도 1명만 생긴다
- 로그인할 때마다 새 세션을 만든다. 같은 브라우저의 이전 세션은 그때 무효가 된다
- 로그인은 마지막 요청 뒤 14일 동안 유지된다. 요청할 때마다 다시 14일로 늘어난다
- 로그아웃하면 그 세션은 바로 무효가 된다
- 로그인을 마친 뒤 가는 주소는 서버 설정으로 고정한다. 요청으로 목적지를 바꿀 수 없다
- 세션 ID 원본과 카카오 토큰은 DB에 저장하지 않는다. 카카오 `code` · 토큰 · client secret · 세션 ID는 로그에 남기지 않는다

## 하지 않는 것

- 다른 기기 · 브라우저의 세션을 한꺼번에 끝내는 로그아웃은 없다. 로그아웃은 요청한 세션 하나만 끝낸다
- 카카오 토큰을 보관하지 않으므로, 로그인한 뒤 강사 대신 카카오 API(메시지 보내기 등)를 부르지 않는다
